# Netzwerkdokumentation

In diesem Kapitel dokumentiere ich den Aufbau des Schulnetzwerks. Die Netzwerkdokumentation zeigt die physikalische und logische Struktur, die Geräte, die IP-Adressierung, die VLANs und das Sicherheitskonzept.

## Übersicht

| Datei | Inhalt |
| --- | --- |
| [topologie.md](topologie.md) | Beschreibung der Topologie mit Hauptstandort, Aussenstelle und WAN-/Internet-Segment |
| [geraeteliste.md](geraeteliste.md) | Übersicht der eingesetzten Router, Switches, Clients, Server und Access Points |
| [ip_adressierung.md](ip_adressierung.md) | Dokumentation der IP-Netze, Gateways und wichtigen Geräteadressen |
| [vlan_uebersicht.md](vlan_uebersicht.md) | Übersicht der VLANs und ihrer Zuordnung zu Benutzergruppen |
| [sicherheitskonzept.md](sicherheitskonzept.md) | Beschreibung der Segmentierung, VPN-Sicherheit und Zugriffskontrolle |

## Zweck dieses Kapitels

Dieses Kapitel soll dem Leser einen vollständigen Überblick über mein Netzwerk geben. Es ist die Grundlage, um die späteren technischen Kapitel zu VLAN, WLAN, VPN und Tests einordnen zu können.
