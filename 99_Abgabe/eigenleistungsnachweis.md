# Eigenleistungsnachweis

## Eigenleistung

Ich habe das Schulnetzwerk-Projekt selbständig strukturiert, dokumentiert und mit Nachweisen ergänzt. Die Dokumentation wurde in Markdown erstellt und im Repository versioniert.

## Meine Arbeiten

| Bereich | Eigenleistung |
| --- | --- |
| Repository-Struktur | Ordnerstruktur für die Abgabe aufgebaut |
| Netzwerkdokumentation | Topologie, Geräte, IP-Adressen, VLANs und Sicherheitskonzept dokumentiert |
| VLAN | VLAN-Konzept, Konfiguration, Trunking und Tests beschrieben |
| WLAN | WLAN-/Gastbereich, SSID-/VLAN-Mapping und Sicherheit dokumentiert |
| VPN | IPsec Site-to-Site-VPN anhand der Screenshots dokumentiert |
| Test und Validierung | Testplan, Testprotokoll und Troubleshooting erstellt |
| Monitoring | Grenzen von Packet Tracer beschrieben und Grafana/WireGuard-Konzept ergänzt |
| Reflexion | Lernprozess, Probleme und Fazit formuliert |
